# AI Coding Agent Instructions

## Critical User Directives

1. **Explicit Permission Required:** NEVER execute code modifications, add new features, or alter existing logic without explicit, prior permission from the user ("سیامک"). 
2. **Analysis First:** When investigating issues, limit actions to read-only commands (e.g., `cat`, `grep`, `ls`, SQL queries) to gather information. Report findings and wait for authorization before applying any fix.
3. **No Assumptions:** Do not assume implied consent. A request for analysis or explanation is NOT a request to implement the solution immediately.
4. **Persistent Rule:** This directive is absolute and supersedes any internal defaults for proactive implementation.
