# ایجنت ردیابی هوشمند و ضد سرقت موبایل (Fleet Mobile Agent)

این ماژول یک برنامه بومی (Native Android) است که برای تبدیل گوشی‌های هوشمند اندرویدی به ردیاب‌های آنلاین و امنیتی توسعه یافته است.

## ویژگی‌ها و قابلیت‌های ضد سرقت:
1. **ردیابی زنده در پس‌زمینه (Background Foreground Service):**
   - ارسال مختصات ماهواره‌ای دقیق (Latitude, Longitude, Altitude, Speed, Battery) به سرور ناوگان هر ۲۰ ثانیه یا به ازای هر ۱۰ متر جابجایی.
   - شروع مجدد خودکار پس از خاموش و روشن شدن گوشی (`BOOT_COMPLETED`).

2. **تشخیص هوشمند تعویض سیمکارت و پشتیبانی کامل دو سیمکارته (Dual-SIM Whitelist):**
   - سیستم به طور هوشمند شناسه سخت‌افزاری تمام سیمکارت‌های فعال روی گوشی (هم اسلات ۱ و هم اسلات ۲) را در لیست سفید (Whitelist) ذخیره می‌کند.
   - جابجایی سیمکارت بین اسلات‌ها یا خارج کردن یکی از سیمکارت‌ها باعث آلارم کاذب نمی‌شود.
   - به محض اینکه سارق یک سیمکارت ناشناس و غریبه در هر کدام از اسلات‌ها بیندازد، سیستم بدون نیاز به اینترنت و با استفاده از شارژ سیمکارت سارق، پیامک مخفی حاوی لینک دقیق گوگل‌مپ و مشخصات سیمکارت سارق را به شماره اضطراری مالک می‌فرستد.

3. **کنترل و ردیابی آفلاین با پیامک (SMS Commands):**
   - در صورت خاموش بودن اینترنت، صاحب گوشی می‌تواند با ارسال پیامک `LOC#` موقعیت لحظه‌ای را دریافت کند.
   - با ارسال پیامک `SIREN#`، صدای آژیر خطر با حداکثر ولوم پخش می‌شود.

4. **سیستم ضد دستکاری (Device Admin):**
   - جلوگیری از حذف یا توقف برنامه توسط افراد متفرقه و سارقان.
   - ثبت رویداد امنیتی در صورت ۳ بار اشتباه وارد کردن رمز قفل صفحه.

## نحوه بیلد APK با GitHub Actions:
فایل گردش‌کار `.github/workflows/build-apk.yml` تنظیم شده است تا به محض هر Push در گیت‌هاب، فایل APK نهایی به صورت خودکار کامپایل شده و در تب Actions به عنوان Artifact برای دانلود قرار گیرد.
